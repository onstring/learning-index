  • >> I wondered if maybe it was practical to create a new language by removing stuff from C++. What would be removed and why? The issue is that whatever is left would not be C++ and it would be difficult to get everyone to agree about what should be removed. Hyrum's law ( https://www.hyrumslaw.com/ ) also applies, so you can't remove anything without breaking things for someone. If you want a simpler, yet quite capable modern language, I would recommend Go ( https://go.dev/ ). It might not replace C++ depending on your use case (for example: embedded programming or writing operating system drivers), but it is a good general purpose language that is easy to learn and easy to use.
