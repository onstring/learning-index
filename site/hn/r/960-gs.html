960 Grid System

https://960.gs · 中文 (Google 翻译)

Learn to use a 960-pixel grid system for web development with 12 or 16 columns for consistent layout design.

Reference Intermediate Recommended by 3 different commenters across 2 years (2009–2010)

  • Of course it's good for a web developer to have a feel for design! At least at some level. Getting a feel for flow, balance, typography and colors at least at a level where you can recognize what makes a great design great, is a huge advantage. There are some great resources for design, which I think can be approached by a typical programmer. * Grid layouts such as http://960.gs/ and http://www.blueprintcss.org/ * Typogrify which helps you create better typography (and is also a resource for stuff to think about!) http://code.google.com/p/typogrify/ * Compass makes it easier to create good design with standards http://compass-style.org/ * Good read on typography http://informationarchitects.
