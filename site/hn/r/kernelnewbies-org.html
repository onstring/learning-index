Linux Kernel Newbies

https://kernelnewbies.org · 中文 (Google 翻译)

Learn to contribute to the Linux kernel through tutorials, mentoring, and community support for new developers.

Tutorial Intermediate Recommended by 3 different commenters across 3 years (2011–2014)

Discussed on Hacker News: Linux Kernel Newbies (53 points)

What Hacker News says

  • If you want to contribute to the Linux kernel, you may want to start here: http://kernelnewbies.org/ (Found via Google search on [linux kernel development].) Start with a small project, maybe just learning how to compile and install your own custom kernel. Then go look for bugs that other people would like fixed but don't have time to fix, and see if you can fix them. There're a bunch of guidelines (that I'm not too familiar with...I don't personally do kernel hacking) to getting your patch accepted, but I think there's pretty substantive mentoring available for new developers. Good luck.

    nostrademons, 2014 · comment · in Ask HN: How do I get my motivation back?

  • http://kernelnewbies.org is an excellent resource to get you started. They recommend starting here: http://kernelnewbies.org/KernelJanitors . I would also recommend subscribing to the KernelNewbies mailing list, to participate and ask questions. Good luck!

    xtacy, 2012 · comment · in What's new in Linux 3.2

  • In case you don't watch the whole video: http://kernelnewbies.org/ A great starting point for kernel hacking.
