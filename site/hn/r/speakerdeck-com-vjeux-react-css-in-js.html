React CSS in JS

https://speakerdeck.com/vjeux/react-css-in-js · 中文 (Google 翻译)

Learn how to style React components using JavaScript, addressing global namespace issues and dependency management in CSS.

Explainer Intermediate Recommended by 3 different commenters across 2 years (2015–2019)

Discussed on Hacker News: React: CSS in JS (33 points)

What Hacker News says

  • Here's the canonical slide deck that kicked off the "CSS in JS" trend. https://speakerdeck.com/vjeux/react-css-in-js The core idea isn't strictly to generate CSS from JavaScript per se, but to generate CSS in whatever code is generating your HTML. In React, that's JS, but if you're generating HTML server-side in PHP or Ruby, the argument calls for generating CSS in PHP or Ruby. vjeux's talk identifies seven problems: 1) global namespace: CSS has a page-global namespace for classes 2) dependency management: if you forget to include CSS, but another module/component on the page includes the CSS you need, your code will seem to work, until they remove their dependency and your code will magical

    dfabulich, 2019 · comment · in Revisiting the Rendering Tier

  • Hey Iwein, there are couple fundamental issue with the way we style HTML elements today. CSS is exposing every declaration into a global namespace. This makes it to eliminate dead code as it is hard to figure out where it is used. Many techniques like BEM were invented and declared as "the right way" to do styling. I don't know if inline-styles defined in JS are the end-game, but working with it in combination with building components turned out to be working way better for us than using CSS. If you want to know more about it I highly recommend this slidedeck: https://speakerdeck.com/vjeux/react-css-in-js
