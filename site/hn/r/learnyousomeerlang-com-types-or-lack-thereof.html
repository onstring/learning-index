Learn about Erlang's dynamic typing system, type guards, conversions, and static type inference without static type systems.

  • Agreed on the typing, however. Have you guys looked into Dialyzer? Dialyzer is a static analysis tool for Erlang and other languages that compile to BEAM bytecode for the Erlang VM. It can analyze the BEAM files and provide warnings about problems in your code including type mismatches and other issues that are commonly detected by static language compilers. The analysis can be improved by inclusion of type hints (called specs) but it can be useful even without those. For more information I highly recommend the Success Typings paper that describes the theory behind the tool.
