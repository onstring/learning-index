NIST Special Publication 800-63B

https://pages.nist.gov/800-63-3/sp800-63b.html · 中文 (Google 翻译)

Learn about digital identity guidelines for authentication and lifecycle management, including password policies and security best practices.

Reference Intermediate Recommended by 3 different commenters across 3 years (2017–2022)

Discussed on Hacker News: New NIST password guidelines: don't require character types or rotation (642 points)

What Hacker News says

  • https://pages.nist.gov/800-63-3/sp800-63b.html#memsecret They refer to it as a “Memorized Secret“. The appendix, “Strength of Memorized Secrets” is informative rather than a guideline, but I would recommend quoting it too in such discussions: > composition rules, which require the user to choose passwords constructed using a mix of character types, such as at least one digit, uppercase letter, and symbol. However, analyses of breached password databases reveal that the benefit of such rules is not nearly as significant as initially thought… although the impact on usability and memorability is severe

    lelandfe, 2022 · comment · in Password Requirements: Myths and Madness

  • > A trivial example: IT requires users to change their passwords every N days. So users start with "password", and when they are required to change it, they use "password1", then "password2", and so on. Fortunately in the latest NIST Digital Identity Guidelines this case is explicitly discouraged [1]: Do not require that memorized secrets be changed arbitrarily (e.g., periodically) unless there is a user request or evidence of authenticator compromise. [1]: https://pages.nist.gov/800-63-3/sp800-63b.html#usabilitycomm...

    sigsergv, 2018 · comment · in Trump’s cell phone use is security “nightmare” waiting to happen, lawmakers say

  • It should be mentioned that the NIST reference Jeff sites is only a draft, started last year. https://pages.nist.gov/800-63-3/sp800-63b.html It's a great one. Not only does i recommend against composition rules, but > Verifiers SHOULD NOT require memorized secrets to be changed arbitrarily (e.g., periodically) Oh, if there is a sin against passwords it is forcing quickly memoizable (i.e. simpler) passwords.

    paulddraper, 2017 · comment · in Password Rules Are Bullshit
