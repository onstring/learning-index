Designing with Types

https://fsharpforfunandprofit.com/series/designing-with-types/ · 中文 (Google 翻译)

Learn to use types to make designs more transparent and improve correctness through practical examples in F#.

Course Intermediate Recommended by 3 different commenters across 1 year (2023–2023)

What Hacker News says

  • They're extremely useful in capturing the "business rules" for a given domain, particularly when it's a restricted domain: if something can only be `A | B | C`, being able to make that explicit, have it checked exhaustively everywhere by the compiler, and be able to dispatch on it easily using `match` is really powerful. That's because it comes with a statically-tracked "tag" (so: sometimes called a "tagged union") that the compiler can use to check you. You can write the same thing with a `union` in C or C++, with an `enum` to tag it, but you're doing that by hand rather than having it built in.
