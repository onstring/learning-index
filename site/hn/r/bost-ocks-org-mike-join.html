Thinking with Joins

https://bost.ocks.org/mike/join/ · 中文 (Google 翻译)

Learn how to bind data to DOM elements using D3.js joins for creating dynamic visualizations.

Explainer Intermediate Recommended by 3 different commenters across 3 years (2012–2019)

Discussed on Hacker News: D3: Thinking with Joins (94 points)

What Hacker News says

  • Most d3 examples will have a "draw" function that you call every time the data is updated. You basically bind your dataset to SVG elements, then D3.js will diff the new data with that bound data and decide what to update. A good intro to the concept: https://bost.ocks.org/mike/join/ I personally usually am working in a React app, so I would use that to render (and update) the chart. However, that's a pretty complicated example to start with! You might be better off using one of the higher-level libraries, like this one: https://apexcharts.com/javascript-chart-demos/candlestick-ch... There are a ton to choose from (just google `js candlestick chart`), and they can be pretty customizeable.

    wattenberger, 2019 · comment · in How to learn D3.js

  • This book is very good and I highly recommend it if you're just starting out. But I didn't feel like I really understood how d3 works until I read these two articles by Mike Bostocks himself. http://bost.ocks.org/mike/selection/ http://bost.ocks.org/mike/join/ IME, understanding joins and selections is essential when using d3.

    allenkim67, 2014 · comment · in What D3.js is Not

  • Agreed. This seems like a better introduction than other tutorials I've seen, but it could just be that I've already grokked D3's data binding model through some tutorials plus a bit of trial and error. This is another must-read: http://bost.ocks.org/mike/join/

    tlrobinson, 2012 · comment · in D3, Conceptually - Lesson 1
