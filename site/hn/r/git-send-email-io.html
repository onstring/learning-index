Learn to use email with git

https://git-send-email.io · 中文 (Google 翻译)

Students learn to configure and use git send-email for contributing to email-driven projects like the Linux kernel.

Tutorial Intermediate Recommended by 3 different commenters across 2 years (2019–2023)

Discussed on Hacker News: Show HN: Learn to use email with Git (170 points)

What Hacker News says

  • It is really easier than it looks! Took me a while to try it, but then I realized it's really super easy: run the git command to create the e-mail, send the e-mail, and on the reviewer side just run the command to apply it. This is a nice tutorial, too, but I would recommend reading Drew Devault's posts first (and watching his short videos): https://git-send-email.io/

    palata, 2023 · comment · in git-appraise – Distributed Code Review for Git

  • I think you should give email its fair shake. There's a good tutorial here: https://git-send-email.io And the video on this website shows you how the maintainer side could work: https://aerc-mail.org And remember, the email client you use for hacking needn't be the same as your everyday client.

  • It's really not that bad, it's just different. There's pros and cons. https://git-send-email.io/ has a great tutorial for getting started. There's probably also a lot of emacs contributors that use emacs as their mail client that would be disrupted by replacing it with something web based.
