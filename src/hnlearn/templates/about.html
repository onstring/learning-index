About

{{ site.name }} lists free online learning resources that Hacker News commenters keep recommending: tutorials, courses, free books, reference documentation and single explanatory posts. It is built in the spirit of hackerbooks.org and hackertube.org, but for material you can read for free in your browser.

How a resource gets in

  1. Every Hacker News comment from 2006 to the dataset's last month is scanned for a link together with a recommendation phrase such as "highly recommend", "great resource" or "start with".
  2. Links are normalised and counted by distinct commenters. A URL qualifies when at least {{ site.min_people }} different people recommended it. Hosts that are never a resource in their own right (video sites, shops, social networks, code hosting) are excluded.
  3. Each page is fetched once to check it is still up and to read its title and opening text.
  4. A local decision model (Cloudflare's clef-flash, run with Ollama) answers a fixed rubric for each URL: is it free to read in full, does it teach something, is it timeless, is it video, a code repository or a page for a paid book? It also picks a topic, a resource type and a difficulty. A URL is kept when the model's probability that it is a free online learning resource is at least {{ site.keep_threshold }}.
  5. A second local model (Qwen3 30B-A3B) writes the one-sentence description from the page text and the comments.

On a hand-labelled sample of 100 URLs the keep decision was right about 85 to 89 percent of the time, so expect some misses and some items that should not be here. Rankings are by number of distinct recommenders, then by the number of years over which the recommendations were made. Nothing here is paid placement.
